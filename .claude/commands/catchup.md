Read the following files to understand current project state:

1. `docs/PROGRESS.md` — what was done recently and what's next
2. `docs/PRD.md` — project requirements and scope (non-goals are critical)
3. `tasks/lessons.md` — anti-patterns to avoid (review before writing code)
4. `PROJECT_STATE.json` — dynamic state, scores, decisions

Then run: `git log --oneline -10` and `git diff main --stat` (if on a branch).

Summarize:
- What has been done recently
- Current project state and quality metrics
- What comes next
- Any open issues or blockers
